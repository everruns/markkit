How do I reverse a linked list in place?

Asked 3 years ago · Viewed 48k times
312

I have a singly linked list and want to reverse it without allocating a new list. My attempt loses the rest of the list after the first node:

while node:
    node.next = prev
    prev = node
    node = node.next

You overwrite node.next before saving it. Keep a reference to the next node first:

def reverse(head):
    prev = None
    node = head
    while node:
        nxt = node.next
        node.next = prev
        prev = node
        node = nxt
    return prev

This runs in O(n) time and O(1) extra space.
