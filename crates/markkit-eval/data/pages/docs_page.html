Configuration

Tideline reads its settings from tideline.toml in the project root. Every key is optional.

Options

KeyTypeDefaultDescription
workersinteger4Number of worker threads
timeoutstring30sRequest timeout
retrybooleantrueRetry failed requests once

Example

[server]
workers = 8
timeout = "45s"

[cache]
enabled = true

Loading from code

Use Config::load to read the file manually:

use tideline::Config;

fn main() -> anyhow::Result<()> {
    let cfg = Config::load("tideline.toml")?;
    println!("{} workers", cfg.workers);
    Ok(())
}

Warning: unknown keys are rejected at startup.

See environment variables to override settings per deployment.
